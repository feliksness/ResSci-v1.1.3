# Evidence Table and Claim Map

A control mechanism against hallucination and citation error. Every claim in the final article should trace to a row here.

## A. Evidence table (one row per source)

| ID | Source (short citation) | Access | Type / design | Population / data / system | Methods (key features) | Main result (exact, with numbers and units) | Limitations / risk of bias | Funding / COI | Status (peer-reviewed, preprint, corrected, retracted) | Claims supported |
|---|---|---|---|---|---|---|---|---|---|---|
| S1 | | [FT] | | | | | | | | C1, C3 |
| S2 | | [AB] | | | | | | | | C2 |

Access labels: `[FT]` full text read, `[AB]` abstract only, `[MD]` metadata only, `[SEC]` via secondary source, `[UNV]` unverified.

## B. Claim map (one row per major claim)

| ID | Claim (as it will appear in the article) | Supporting sources | Contradicting / qualifying sources | Evidence strength (GRADE level or category) | Key limitations | Permitted wording |
|---|---|---|---|---|---|---|
| C1 | | S1, S4 | S6 | Moderate | | "Available evidence suggests..." |
| C2 | | S2 | — | Limited | Single study, abstract only | "One study reported..." |

## C. Checks before writing

- [ ] Every claim has at least one supporting source that addresses that specific claim.
- [ ] Contradicting evidence has been searched for and recorded for each major claim.
- [ ] Sources counted as independent really are independent (different datasets, groups, experiments).
- [ ] Numbers in column "Main result" were copied from the source, not recalled.
- [ ] Wording in column "Permitted wording" matches the evidence strength.
